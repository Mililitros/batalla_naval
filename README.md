# Batalla Naval
TP integrador (5ª Instancia de Evaluación) de Paradigmas de Programación, UTN FRRe. Juego de Batalla Naval de un jugador contra la IA, desarrollado en Smalltalk (Pharo) con Programación Orientada a Objetos.
## Requisitos: 
•	Pharo (versión usada: 12)
o	Desde Pharo Launcher:
1-	Apretar el botón New en la esquina izquierda
2-	En la columna izquierda apretar Deprecated distributions
3-	Elegir Pharo 12.0 – 64bit

•	Git
## Cómo cargar el código
1.	Clonar el repositorio con Iceberg
o	Abrir Pharo y entrar a Iceberg (World Menu, o Ctrl + O y luego I).
o	Clic en Add → Clone from github.com.
	Ingresar:
1.	Owner name: Mililitros
2.	Project name: batalla_naval
3.	Protocolo: HTTPS
https://github.com/Mililitros/batalla_naval.git  y presionar OK.
2.	Cargar los paquetes
o	Doble clic sobre el repositorio clonado → pestaña Packages.
o	Clic derecho sobre cada paquete BatallaNaval-* (estado Not loaded) → Load.
## Cómo ejecutar el juego
1. Abrir un Playground (Ctrl + O y luego W)
2.  ejecutar:
		ControladorGrafico abrir.
## Cómo correr los tests
World Menu → Test Runner → seleccionar los paquetes BatallaNaval → Run Selected.
